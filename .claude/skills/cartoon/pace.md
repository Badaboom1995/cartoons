# Темп

Эталон: `design-girl/episodes/ep-003-posidi-za-menya`. Пользователь назвал его темп правильным: не слишком быстро и не слишком медленно. Цифры сняты с его `timeline.json`.

Это ориентир, а не норматив. Отклонение значит «посмотри на это место», а не «исправь автоматически».

## Эталон в цифрах

| Что | Сколько |
|---|---|
| Длина ролика | около 60 с |
| Объём | около 115 слов, 23 реплики, 28 шотов |
| Доля речи | две трети времени |
| Скорость речи | около 3 слов в секунду у всех героев |
| Пауза между репликами | 0,17 с, ответ начинается с первого кадра нового шота |
| От конца реплики до склейки | 0,17 с |
| Длина шота | обычно 2 с, от 0,6 до 4,7 с |
| Короткая немая реакция | 0,7–0,8 с |
| Главная немая реакция (шок, восторг) | 1,4–2 с |
| Паузы длиннее секунды | 4 на ролик: смена времени суток, два шока, восторг |
| Открывающий общий план до первой реплики | около 3 с |
| Закрывающий план | около 2 с |
| Шот с надписью, которую надо прочитать | не короче 1,3 с |

Настройки звука, которые дают этот темп, уже стоят в шаблоне `episode.json`:

```json
"pacing": { "start": 0.2, "line_gap": 0.14, "tail": 0.17, "end": 0.5, "tempo": 1.2, "max_pause": 0.14 }
```

## Что выбивает зрителя из потока

- Реакция затянута: тишина висит, разговор остановился.
- Реакция или событие проскакивает так быстро, что его не успеть понять.
- Шот обрывается резко: фраза или действие не успели закончиться.
- Шот начинается без подготовки: зритель не понял, где он и кто говорит.

В жизни разговор не замирает на каждой эмоции, поэтому реакция обычно идёт вместе с репликой или поверх следующей. Отдельная немая пауза остаётся для одного-двух главных ударов.

## Как пользоваться

- **Сценарий.** Длину считай до озвучки: реплика длится примерно `слова / 3 + 0,17` с, к сумме прибавь немые шоты и паузы. На минуту помещается около 115 слов.
- **Озвучка.** Сравни получившийся `timeline.json` с таблицей: скорость речи по героям, паузы между репликами, длину шотов, число пауз длиннее секунды, шоты с надписями.
- **Анимация.** Действие в шоте заканчивается до склейки, а не обрывается ею. Движение, которое зритель должен понять, занимает не меньше короткой реакции.
