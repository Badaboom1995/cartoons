# Cartoons

Скетчи с 3D-персонажами. Одна папка на главного героя (ГГ).

Здесь только карта папок. Как делается эпизод, по шагам и с проверками, описано в скилле `cartoon`.

```
cartoons/             корень репозитория
├── CLAUDE.md         правило для агентов: работать через скилл cartoon
├── .claude/skills/cartoon/   сам скилл: шаги, проверки, темп
├── .env.local        ключ озвучки, в git не попадает
├── _template/        заготовка нового ГГ и нового эпизода
├── _tools/           общие инструменты: audio (озвучка, плеер, таймлайн), subtitles (субтитры в видео)
└── <character>/
    ├── character.md  кто это: характер, внешность, отношения
    ├── voice.md      голос, манера речи, словечки
    ├── style.md      стиль роликов: формат, юмор, камера, динамика, цвет
    ├── cast/         повторяющиеся второстепенные персонажи
    ├── scene/        всё, что переиспользуется между эпизодами
    └── episodes/     конкретные эпизоды
```

## Что куда класть

| Что | Куда |
|---|---|
| Модель и риг ГГ или постоянного героя | `scene/characters/<name>/` |
| Комната, улица, любая локация | `scene/locations/<name>/` |
| Реквизит, который встречается больше одного раза | `scene/props/` |
| Общие материалы | `scene/materials/` |
| Световые схемы | `scene/lighting/` |
| Готовые камеры и ходы камеры | `scene/cameras/` |
| Движения тела (ходьба, idle, жесты) | `scene/animations/body/` |
| Мимика, моргание, липсинк | `scene/animations/face/` |
| Статичные позы | `scene/animations/poses/` |
| Повторяющиеся музыка и звуки | `scene/audio/` |
| Описание постоянного второстепенного героя | `cast/<name>.md` |
| Описание эпизодического героя | `episodes/<episode>/cast.md` |
| Модель или реквизит только для одного эпизода | `episodes/<episode>/assets/` |

Если вещь из эпизода понадобилась второй раз, перенеси её в `scene/`.

## Объекты и анимации в Blender

**Объект** это геометрия, риг и материалы. Он хранится в своём `.blend`, собранный в коллекцию с именем героя или предмета.

**Анимация** (Action) это только ключи движения по именам костей, без геометрии. Она тоже лежит внутри `.blend`, но подходит любому персонажу с такими же именами костей. Поэтому анимации хранятся отдельно от модели.

Как это собирается в эпизоде:

1. **Персонажи, локации, реквизит: Link + Library Override.** В эпизоде лежит ссылка, а не копия. Правка модели в `scene/` появляется во всех эпизодах.
2. **Анимации: Append.** В эпизод попадает своя копия Action, её можно подправить под сцену, не ломая библиотеку. Куски раскладываются на дорожках NLA.
3. **Только относительные пути.** Из файла эпизода путь к сцене выглядит так: `//../../scene/characters/design-girl/design-girl.blend`.

Не переименовывай кости и коллекции в файлах `scene/`: на этих именах держатся ссылки и анимации.

## Папка эпизода

Новый эпизод это копия `_template/episodes/_template` с именем `ep-NNN-slug`, например `ep-003-coffee`.

| Что | Где |
|---|---|
| На каком шаге эпизод и что одобрено | `status.md` |
| Журнал правок: замечания дословно и что изменено | `log.md` |
| Сценарий для чтения и одобрения | `script.md` |
| Эпизодические герои | `cast.md` |
| Сцены, шоты и реплики для инструментов | `episode.json` |
| Те же шоты и реплики в кадрах, по ним строится анимация | `timeline.json` |
| Голоса, звуки, музыка | `audio/voice/`, `audio/sfx/`, `audio/music/` |
| Скрипты сборки сцены | `scripts/` |
| Титры и картинки для постобработки | `overlays/` |
| Файл сцены | `ep-NNN.blend` |
| Аудиоверсия, плеер, готовое видео | `renders/` |
| Копии сборок по раундам и отчёты воркеров | `.work/` |

Папки `renders/` и `.work/` игнорируются git.

## Новый ГГ

Скопируй `_template` в `<character-name>` в корне репозитория, удали из копии `cast/_template.md` и `episodes/_template`, заполни `character.md`, `voice.md`, `style.md`.

Бланки живут только в `_template/`.
